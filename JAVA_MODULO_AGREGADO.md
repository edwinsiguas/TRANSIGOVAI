# Módulo Java agregado al proyecto MTC Marcona

Se agregó la carpeta `java-service/` con un servicio Spring Boot separado para exportar reportes Excel. Integra Apache POI, Guava, Apache Commons Lang, Commons IO, Commons Codec y Logback. La aplicación original React/PHP queda preservada.

**Para ejecutar:** ver `java-service/INSTRUCCIONES_WINDOWS.md`.

**Nota académica:** el módulo incorpora Java real, pero no debe afirmarse que ya representa el 30 % del proyecto sin aplicar el método de medición indicado por el docente y revisar el código completo.
